# Trained Models

This directory contains the trained machine-learning models and configuration files used by NetGuard ML.

## Multiclass Detection
- `netguard_multiclass_model.joblib`
- `netguard_multiclass_model_v3.joblib`
- `netguard_multiclass_model_v4.joblib`

## Experimental Anomaly Detection
- `netguard_isolation_forest_experimental.joblib`
- `netguard_isolation_forest_config.json`

The application loads these files from the `models` directory. Keep their filenames unchanged.

**Note:** Model files must be downloaded or added separately if they are not included in this repository.
